DnD Character Creator:

This app is pretty simple to run, in the root directory of the project just run streamlit run app.py and a window should appear with the web app.

Inside of the web app there is only one thing for users to do, input a prompt to create a DnD character. There are sometimes issues with the response time from the APIs used,
so run the prompt again if there are any errors! The character creation process can often take a minute or two so make sure to be a bit patient (progress updates will appear in the terminal after each method is run).

Enjoy creating characters!!!
